# Tailchrome v0.1.15

IPv6 subnet routing, clearer device and profile controls, and fixes for proxy
authentication and helper installation.

## Updating

Update the extension and helper to get all improvements. v0.1.15 keeps the
authenticated proxy protocol introduced in v0.1.14; compatible v0.1.14 helpers
remain usable while you update. If upgrading from v0.1.13 or earlier, update
both components before resuming protected browsing. Firefox 142 or later is
still required.

**The Windows binaries in this release are unsigned.** This includes the x64
and ARM64 raw helpers and the x64 MSI, including its embedded helper. SignPath
test signing has passed, but production certificate issuance and release
integration are pending. The test certificate is not used for releases.

The PowerShell installer requires a valid Authenticode signature by default.
After reviewing this exception, users choosing this unsigned release can run
the installer downloaded from this release with:

```powershell
& .\tailchrome-install.ps1 -Version v0.1.15 -AllowUnsigned
```

`-AllowUnsigned` accepts an absent signature, not an invalid one, and does not
override antivirus protection. Checksums verify the downloaded bytes; they do
not provide a Windows publisher signature. Close browsers using Tailchrome
before upgrading the Windows helper.

## Routing and connection fixes

- Reach approved IPv6 subnets through subnet routers in Chrome and Firefox,
  alongside existing IPv4 support. Subnet matching does not resolve hostnames
  through local DNS.
- Reject new subnet routes that overlap forbidden destinations, including broad
  prefixes containing those addresses. Protected routes remain blocked during
  helper outages and proxy authentication setup.
- Fix Chrome HTTPS requests from other extensions failing proxy authentication.
  Tailchrome prepares Chrome's proxy credentials before enabling protected
  routes and refreshes them when the helper restarts. Traffic stays blocked if
  authentication setup fails.
- Keep informational Tailscale experimental-build notices out of health warnings
  and warning badges while retaining actionable warnings.

## Popup improvements

- Preview five devices with online devices first, expand the list with **View
  all**, and search across the full device list. Click an IP address to copy it
  without opening the device's actions.
- Distinguish confirmed browser routing from the Tailscale node's connection.
- Keep the confirmed **Active** profile visible while a switch is pending,
  prevent conflicting actions, and show retry guidance if switching fails or
  the helper does not confirm within 20 seconds.

## Installation and maintenance

- Fix terminal installation on macOS with its stock Bash and BSD tools.
- Add `--user-data-dir` to the Bash installer for custom Chromium data
  directories, and preserve it in the removal command.
- Improve Windows installer errors when antivirus blocks or quarantines the
  helper, with guidance for collecting the detection details.
- Update development dependencies and expand browser authentication, installer,
  and Windows validation coverage.

See [helper installation](https://github.com/dantraynor/tailchrome/blob/v0.1.15/docs/helper-installation.md)
for upgrade, repair, and removal instructions.
